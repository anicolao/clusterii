# Contextual arrival reports

The selected system opens its latest already-authorized arrival record. Back/Escape restores that system's layer and opener; Inspect surface opens current authorized control. The immutable outcome is explicitly historical. The global report history remains available when the selected system has no loaded report.

`aftermath.spec.ts` reuses feature010's real four-login/formation/dispatch/leased-settlement setup and authenticated SDK readers. It adds the player-visible contextual loop, next-tick immutability, reload, foreign-read denial and separate normal-motion captures. No force, ownership, report or service result is injected. Budget:220 ticks,240s total,30s steps,10s assertions; up to24 captures/viewport. Test-only fixed catalogue/domain clocks and leased scheduler delivery are labeled. Existing feature010/procedural coverage is unchanged.

`components.spec.ts` uses the actual shared ArrivalReports in the existing reducer-derived gallery and interactive lab; this is component evidence, not a substitute for real service acceptance. Generated screenshots/stories are retained outside the repository until independent review; no approved baseline exists for this feature yet.
