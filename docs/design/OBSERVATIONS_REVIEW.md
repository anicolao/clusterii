## Acquisition and privacy

After each authoritative production transition, one scan uses the nearest owned orbital sensor and the beginning-of-tick scanning level. Distance uses the stored light-year coordinates, not renderer scale. Probability is `min(1, 10 L² / distance)`, with certainty at zero. Unified owned systems need no roll. A surface holding alone supplies no orbital sensor. Fleets and fleet sensors are not implemented in this slice.

A domain-separated server HMAC binds the original private 256-bit campaign seed to campaign, observer, target and tick. Its 48-bit draw is persisted in canonical encrypted state. Repeat delivery and transaction retry do not reroll; lease/revision fencing is unchanged. Scan draws never use the public map's small PRNG state. Canonical reports use a versioned compact tuple layout; the member view projects explicit fields for that recipient alone. It exposes no seed, draw, other recipient report table, escrow, wallet, research, construction queue or destination. Split-owner holdings retain layer redaction; a separately acquired report supplies only its authorized observation fields.

Reports retain their acquired facts and source when later scans fail. Tick snapshots preserve historical observations in the existing encrypted revision history. Mode migration retains every authorized record and recipient set across paged history, without silently reacquiring intelligence.

## Compatibility and operating boundary

New campaigns store `intelligenceVersion: 1`. Earlier campaigns retain their recorded sensor behavior and encrypted history; the inspector explains how to create a new development campaign with observations. No historical scans or unrecorded outcomes are invented. This is a conservative implementation compatibility choice, not new human approval of proposed rules. There is no automatic migration for older campaigns.

The canonical format reserves room for every player observing every star before accepting more queued work. A 600,000-byte canonical JSON budget leaves envelope/base64 and tick-ledger margin beneath the storage limit. Over-budget admission receives an explicit rejected receipt without discarding acknowledged orders or reports. The twelve-player, 384-star maximum report fixture occupies 562,555 bytes in mock and 562,376 bytes in real encrypted envelopes. This guards the shipped state model; future fleets, diplomacy and additional history structures require renewed capacity evidence.
